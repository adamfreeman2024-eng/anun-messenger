# Anun

Աշխատանքային մեսենջեր, ոչ պատրաստ ապրանք։ 18.10.2026-ի սուր փորձը միայն սա է. մեկ գաղտնագրված նամակ, ռելեն չի կարող կարդալ։

Սա **100% անվտանգ չէ** և դեռ մեսենջեր չէ։ Զանգ, ֆայլ, հավելված և աուդիտ չկան։

## Ինչ կա

- `spike/envelope.py` — X25519 + HKDF-SHA256 + AES-256-GCM (`cryptography` գրադարան, սեփական ծածկագիր չկա)
- `spike/relay.py` — կույր ռելե։ Պահում է ծրար։ Բանալի չունի։ Գաղտնազերծման ֆունկցիա չունի
- `PLAN.md` — ստեղծման պլանը

## Ստուգում

```bash
python3 -m pip install -r requirements.txt
python3 -m unittest spike.test_spike
```

Թեստը ուղարկում է հայերեն նամակ և ստուգում, որ այդ բայթերը ռելեի սկավառակին չկան։

## Կանոններ, որ հաջորդ գործակալը չի խախտում

1. Սերվերին մասնավոր բանալի մի դիր։
2. Նոր ծածկագիր մի գրիր։ Միայն ստուգված գրադարան։
3. Հեռախոսահամարով գրանցում մի ավելացրու։
4. «100% անվտանգ» մի գրիր README-ում կամ կայքում։
5. SimpleX-ի կոդը մի պատճենիր։ Այն AGPL է։
