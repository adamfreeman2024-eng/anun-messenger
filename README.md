# Anun

Աշխատանքային մեսենջեր, ոչ պատրաստ ապրանք։ 18.10.2026-ին կա սուր փորձ, ոչ հավելված։

- Ֆայլը նույն գաղտնագրումով է, մասերով։ Անունը ռելեին չի երևում։
- Ձայնի կադրը գնում է միայն ռելե։ Ռելեն ընկնելիս զանգը կտրվում է, ուղիղ IP չի բացվում։
- Երկու ցատկ. առաջմղիչ ռելեն չի տեսնում ստացողի հերթը։
- QR հրավերի նկար։ Ներսում միայն հրավերի տողն է։
- Ուղարկողը ստացողի ռելեին չի միանում։ Նամակը, փոքր ֆայլը և ձայնի կադրը գնում են առաջմղիչ ռելեով։

Սա **100% անվտանգ չէ**։ Պլանը փակված չէ. իրական հեռախոս, SecureStore, ձայնային կոդեկ, Double Ratchet-ի օտար գրադարան և արտաքին աուդիտ չկան։

## Ինչ կա

- `spike/envelope.py` — X25519 + HKDF-SHA256 + AES-256-GCM (`cryptography` գրադարան, սեփական ծածկագիր չկա)
- `spike/relay.py` — կույր ռելե։ Պահում է ծրար։ Բանալի չունի։ Գաղտնազերծման ֆունկցիա չունի
- `PLAN.md` — ստեղծման պլանը

## Ստուգում

```bash
python3 -m pip install -r requirements.txt
python3 -m unittest spike.test_spike spike.test_phase3 spike.test_continue spike.test_product spike.test_reply spike.test_file_parts spike.test_disappear spike.test_opus spike.test_call_run spike.test_local
```

Թեստը ուղարկում է հայերեն նամակ և ստուգում, որ այդ բայթերը ռելեի սկավառակին չկան։
